Per-element popover

The .exp-popover mounts only when a host passes onElementEvent, so it is reachable from here and from nowhere else in the demo. Hover any node in the tree below and watch the console: every node reports, because every node carries a data-el-id. Only CDN edge is keyboard-reachable — it is the one node with a tip, and tip is what earns a node tabindex="0". Hovering an untipped node opens no popover, by design.

Tab to the tipped node and the popover opens from the keyboard path too. Worth knowing if you write your own probe: it will not open from a scripted el.focus(), because that fires no focusin on an injected SVG element — use a real Tab keypress. Note too that focus opens the popover without reporting an event: onElementEvent carries hover and click only.

The figure no longer carries a native <title> tooltip: it used to show one summary per figure, identical over every node, which on a tree meant the whole tree linearised into one sentence. The accessible name is unchanged — it lives in aria-label, which is what a screen reader uses.
