# Stitch Design Explorations

Two concept screens generated with [Stitch AI](https://stitch.withgoogle.com) for the
next feature of the `explanations` library. Each folder contains the rendered screen
(`screen.png`), the Stitch-generated HTML (`code.html`), and the shared design-system
token sheet (`DESIGN.md`).

Both explorations share the same design system — **"Curio Editorial Learning"**: a
museum-grade editorial aesthetic (Newsreader serif headlines, Plus Jakarta Sans body,
JetBrains Mono data) with parchment surfaces, hairline rules, and per-discipline accent
colors. `DESIGN.md` (identical in both folders) holds the full token definitions and
component specs.

## Concepts

| Folder | Concept |
|---|---|
| [`arrow-of-time/`](./arrow-of-time/) | "Arrow of time" — an interactive simulation/exploration of temporal directionality |
| [`semantic-cartographers-atlas/`](./semantic-cartographers-atlas/) | "Semantic cartographer's atlas" — an interactive, explorable atlas of mapped concept space |

These are design references only — not wired into the library build or tests.
